# 🐘 PHP Learning Repository

Welcome to my PHP learning repository! This project is a hands-on space where I explore the fundamentals of PHP, experiment with syntax, and build mini applications to reinforce my understanding.

## 📚 Learning Source

I followed the excellent [PHP Tutorial For Beginners | FREE PHP Full Course](https://www.youtube.com/watch?v=V821daR3UcM) on YouTube. The tutorial covers everything from basic syntax to building a login system and working with MySQL databases. It’s a great resource for anyone starting out with PHP.

## 🧠 What I Learned

This repository includes code snippets and mini projects based on the following topics:

- ✅ PHP installation (WAMP/XAMPP)
- ✅ Variables, data types, and constants
- ✅ Operators and control structures
- ✅ Functions and string manipulation
- ✅ Arrays (indexed and associative)
- ✅ Cookies and session management
- ✅ Connecting to MySQL and performing CRUD operations
- ✅ Building a basic login application
